Connect to GitHub

The Studio saves your edits straight to the game's GitHub repository . To let it, make a GitHub access key once. It stays in this browser only.

  1. Open github.com/settings/personal-access-tokens/new.
  2. Name it RANGA-SWANG Studio and pick an expiration (one year is fine).
  3. Under Repository access, choose Only select repositories and pick .
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it, and paste it below.

Prefer not to? You can still edit questions on github.com in the content/days folder, or just ask Claude to change them.
